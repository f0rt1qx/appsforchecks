# Receipt Scanner App 🧾

SPA приложение для регистрации пользователей, управления профилем и распознавания кассовых чеков через OCR прямо в браузере.

Проект разработан с фокусом на строгую архитектуру (Clean Architecture) и стилизован под современный тёмный финтех-дашборд. **Backend отсутствует**, все данные надежно хранятся в `localStorage` браузера.

---

## 🛠 Технический стек

- **Фреймворк:** React 19 + Vite
- **Язык:** TypeScript
- **Маршрутизация:** React Router v7 (API v6+)
- **Управление состоянием:** Zustand
- **Стилизация:** Tailwind CSS
- **Распознавание текста (OCR):** Tesseract.js (WebAssembly)
- **Иконки:** Lucide React
- **Хранилище:** браузерный `localStorage`

---

## 📁 Архитектура проекта

Проект построен по принципам **Clean Architecture** (Feature-Sliced Design) для максимальной масштабируемости и чистоты кода:

```text
src/
├── assets/         # Статичные файлы (картинки, шрифты)
├── components/     # Переиспользуемые UI-компоненты (кнопки, инпуты, карточки)
├── config/         # Глобальная конфигурация (например, роутинг)
├── features/       # Бизнес-логика, разбитая по модулям (auth, scanner)
├── hooks/          # Глобальные React-хуки
├── layouts/        # Каркасы страниц (Sidebar, Header, Layout)
├── pages/          # Страницы приложения (привязаны к роутам)
├── services/       # Внешние интеграции (localStorage, OCR API)
├── store/          # Глобальное состояние (Zustand)
├── types/          # Глобальные TypeScript-интерфейсы
└── utils/          # Вспомогательные функции (форматирование дат и т.д.)
```

### Применяемые паттерны проектирования:
- **Repository** — единая точка доступа к `localStorage` через сервисный слой.
- **Observer** — реактивное обновление UI через стейт-менеджер `Zustand`.
- **Adapter** — обёртка над библиотекой `Tesseract.js` для сканирования.
- **Facade** — упрощенный API для сложных действий (например, хук `useAuth()`).
- **Factory** — генерация стандартизированных объектов пользователей и чеков.

## 🚀 Как запустить проект локально

### Требования
- Установленный [Node.js](https://nodejs.org/) (версия 18+ рекомендуется)
- Пакетный менеджер `npm` (устанавливается вместе с Node.js)

### Шаги установки

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/receipt-scanner.git
   ```

2. **Перейдите в папку проекта:**
   ```bash
   cd receipt-scanner
   ```

3. **Установите все зависимости:**
   ```bash
   npm install
   ```
   > **Примечание:** Команда `npm install` автоматически прочитает файл `package.json` и установит все необходимые библиотеки. Вам **не нужно** устанавливать их по отдельности.
   > 
   > **Что установится под капотом:**
   > - `react`, `react-dom` — ядро React
   > - `react-router-dom` — для маршрутизации
   > - `zustand` — для управления состоянием
   > - `tesseract.js` — для OCR-сканера
   > - `lucide-react` — для иконок
   > - `clsx`, `tailwind-merge` — для работы с CSS-классами
   > - *Dev-зависимости:* `vite`, `typescript`, `tailwindcss`, `postcss`, `autoprefixer`, `eslint`

4. **Запустите сервер для разработки:**
   ```bash
   npm run dev
   ```

5. **Откройте приложение:**
   Перейдите в браузере по ссылке, указанной в терминале (обычно это `http://localhost:5173/`).

Чтобы собрать оптимизированную версию проекта для деплоя (публикации в интернете):
